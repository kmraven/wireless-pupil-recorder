# XIAO ESP32S3 Sense Video Recorder

Seeed Studio XIAO ESP32S3 Senseで、JPEGフレームをAVIとしてmicroSDカードへ録画するスケッチです。録画しながら、必要に応じてローカルWi-Fi経由でライブ映像やSDカード内のファイルを確認できます。

## 対象ハードウェアとArduino IDEの設定

このリポジトリは、Seeed Studio XIAO ESP32S3 SenseとOV2640の組み合わせで開発・確認しています。新しいXIAO ESP32S3 SenseにはOV3660が付属する場合があるため、カメラのPIDを起動ログで確認してください。Seeed Studioによるカメラ変更の説明は[公式ガイド](https://wiki.seeedstudio.com/xiao_esp32s3_getting_started/)にあります。

Arduino IDEでは、書き込み前に次を設定してください。

- Board：`XIAO_ESP32S3`
- PSRAM：`OPI PSRAM`

PSRAMが無効だと、起動ログに`SPIRam Total heap 0`や`frame buffer malloc failed`と表示され、カメラを初期化できません。本リポジトリはESP32 Arduino core 3.3.11で動作確認しています。

## 基本的な使い方

1. `config.example.txt`を`config.txt`という名前でmicroSDカードのルートへコピーします。
2. 下記の順序を変えずに設定値を編集します。
3. microSDカードをXIAO ESP32S3 Senseへ挿入して起動します。
4. 停止するときはBOOTボタンを1.5秒長押しします。GPIO5/6へ外付けした状態表示LEDが点滅したら、録画ファイルとSDカードが閉じられており、電源を外せます。LEDを接続していない場合は、シリアルモニタの`SD card unmounted`を確認します。

`config.txt`がない場合は、Wi-Fi OFFと従来のカメラ既定値を使用するファイルをSDカードへ自動生成します。これは、下記の調整済み`config.example.txt`とは異なります。

## config.txt

設定は1項目1行で、行の順序に意味があります。値の後ろには`//`でコメントを書けます。

| 行 | 設定 | 内容 |
|---:|---|---|
| 1 | camera name | ファイル名とmDNSホスト名。英数字とハイフンを推奨 |
| 2 | frame size | `8`はVGA（640×480）、`11`はHD（1280×720）。全対応表は下記 |
| 3 | recording length | AVI 1本の録画秒数 |
| 4 | recording count | 録画するAVIの本数。`0`は無制限 |
| 5 | recording interval | 録画フレーム間隔（ms）。`0`は最速 |
| 6 | speed multiplier | 再生速度倍率。`1`は実時間 |
| 7 | stream interval | ライブ映像のフレーム間隔（ms）。`0`は最速 |
| 8 | timezone | 日本は`JST-9`、UTCは`GMT` |
| 9 | wifi mode | `0`=OFF、`1`=STA、`2`=AP |
| 10 | Wi-Fi SSID | STAでは接続先SSID、APではESP32が作るSSID |
| 11 | Wi-Fi password | STAでは接続先パスワード、APでは8～63文字のAPパスワード |
| 12 | STA IP mode | `0`=DHCP/mDNS、`1`=固定IPv4 |
| 13 | static IPv4 | 固定IPモードで使うESP32のアドレス |
| 14 | gateway | 固定IPモードのゲートウェイ |
| 15 | subnet mask | 固定IPモードのサブネットマスク |
| 16 | DNS server | 固定IPモードのDNSサーバー |
| 17 | camera exposure | `-1`=自動露光、`0～1200`=手動露光値。従来値は`70` |
| 18 | camera gain | `-1`=自動ゲイン、`0～30`=手動ゲイン。従来値は`5` |
| 19 | JPEG quality | `0～63`。小さいほど高画質・大容量。従来値は`12` |
| 20 | brightness | 明るさ。`-2～2`。従来値は`1` |
| 21 | contrast | コントラスト。`-2～2`。従来値は`0` |
| 22 | saturation | 彩度。`-2～2`。従来値は`-2` |
| 23 | auto-exposure level | 自動露出の明るさ補正。`-2～2`。露光が`-1`のとき有効 |
| 24 | auto-gain ceiling | 自動ゲイン上限。`0`=2倍、`1`=4倍、…、`6`=128倍。ゲインが`-1`のとき有効 |
| 25 | white balance | `-1`=OFF、`0`=自動、`1`=晴天、`2`=曇天、`3`=オフィス、`4`=家庭照明 |
| 26 | horizontal mirror | 左右反転。`0`=OFF、`1`=ON |
| 27 | vertical flip | 上下反転。`0`=OFF、`1`=ON |
| 28 | raw gamma | OV2640内蔵のRAW Gamma補正。`0`=OFF、`1`=ON。未指定時は`0` |

### 現在のconfig.example.txt

同梱の`config.example.txt`は、現在の瞳孔撮影で良好だった次の条件に合わせています。

- 録画：`pupilcamera`、640×480、200秒×1本、50 ms間隔、Wi-Fi OFF、`JST-9`
- カメラ：露光・ゲイン自動、JPEG品質`8`、明るさ`0`、コントラスト`0`、彩度`-2`
- 自動制御：AEレベル`2`、ゲイン上限`6`（最大128倍）、ホワイトバランスOFF
- 画像処理：左右・上下反転OFF、RAW Gamma ON

ゲイン上限`6`は128倍を常時使用する指定ではなく、自動ゲインが必要に応じて選べる上限です。暗所には強くなりますが、条件によってノイズが増える可能性があります。10～16行目のWi-Fi情報は公開用プレースホルダーなので、STAまたはAPを使う場合だけ書き換えてください。

### Frame size番号

2行目はESP32ライブラリ内部のenum値ではなく、このレコーダー独自の固定番号です。ESP32ボードパッケージを更新しても、同じ番号は同じ解像度になります。

| 値 | 解像度 | 値 | 解像度 |
|---:|---:|---:|---:|
| 0 | 96×96 | 11 | 1280×720（HD） |
| 1 | 160×120 | 12 | 1280×1024（SXGA） |
| 2 | 176×144 | 13 | 1600×1200（UXGA） |
| 3 | 240×176 | 14 | 1920×1080（FHD） |
| 4 | 240×240 | 15 | 720×1280（縦長HD） |
| 5 | 320×240（QVGA） | 16 | 864×1536（縦長3MP） |
| 6 | 400×296（CIF） | 17 | 2048×1536（QXGA） |
| 7 | 480×320（HVGA） | 18 | 2560×1440（QHD） |
| 8 | 640×480（VGA） | 19 | 2560×1600（WQXGA） |
| 9 | 800×600（SVGA） | 20 | 1080×1920（縦長FHD） |
| 10 | 1024×768（XGA） | 21 | 2560×1920（QSXGA） |

本プロジェクトで使用しているOV2640では、最大`13`（1600×1200）まで使用できます。現在の`config.example.txt`は、安定した瞳孔撮影条件に合わせて`8`（640×480）を使用します。設定を省略した場合の内部既定値は`11`（1280×720）です。AVIの幅・高さは実際に取得した最初のJPEGフレームから記録し、カメラ画像とAVIヘッダーの食い違いを防ぎます。

従来の16行・18行・27行configもそのまま読み込めます。省略されたカメラ項目には、後方互換用の内部既定値（露光`70`、ゲイン`5`、JPEG品質`12`、明るさ`1`、コントラスト`0`、彩度`-2`、ホワイトバランスOFF、反転OFF、RAW Gamma OFF）を使用するため、従来ファイルの撮影条件は変わりません。`config.txt`がないときに自動生成されるファイルも、この内部既定値を使用します。一方、現在の`config.example.txt`は上記の調整済み設定です。

直前の16行形式（recording countが11行目）と、それ以前の旧形式にも対応しています。旧形式では8行目が`ssid1234`ならWi-Fi OFF、`ap`または`wifiman`ならAP、それ以外ならSTAとして扱います。新しく作るconfigでは上表の28行形式を使用してください。

### 露光とゲイン

17行目の露光値はマイクロ秒ではなく、OV2640ドライバーへ渡すセンサー相対値です。手動時は値を大きくすると一般に明るくなりますが、露光が長くなって動きがぶれやすくなり、実効フレームレートにも影響する場合があります。

18行目のゲインは、手動時に値を大きくすると明るくなる一方で画像ノイズが増えます。撮影条件を一定にしたい場合は従来どおり`70`と`5`、照明変化へ自動追従させたい場合は両方を`-1`にします。現在の設定例は両方とも`-1`です。

露光を自動にした場合は23行目で目標の明るさを補正でき、ゲインを自動にした場合は24行目で増幅の上限を設定できます。上限を大きくすると暗所で明るくできますが、ノイズも増えます。25行目のホワイトバランスは、従来動作を保つなら`-1`、照明の色変化へ追従させるなら`0`を使用します。28行目のRAW Gammaは自動調整ではなく、`0`または`1`で補正処理を無効・有効にする設定です。これらを含むカメラ設定の変更は次回起動時に反映され、録画開始前のウォームアップフレームから適用されます。

OV2640の標準ドライバーではシャープネス変更APIが未対応のため、効かない設定はconfigへ追加していません。

## Wi-Fiモードと接続先

### 0: OFF

Wi-FiとWebサーバーを起動しません。SDカードだけで運用するときの省電力設定です。10～16行目は使用されませんが、行位置を保つため削除しないでください。

### 1: STA（ローカルWi-Fiへ接続）

XIAO ESP32S3 Senseは2.4 GHz Wi-Fiへ接続します。PCも同じローカルネットワークへ接続してください。

起動時のSTA接続では`pool.ntp.org`から日時を取得し、8行目のタイムゾーンを適用します。同期を最大約15秒試してから録画処理を続行するため、インターネットへ接続できないネットワークでは日時が正しくない場合があります。

DHCP/mDNSを使う例：

```text
pupilcamera  // camera name
8  // frame size
200  // recording length
1  // recording count
...
1  // wifi mode
YOUR_2G_WIFI_SSID
YOUR_WIFI_PASSWORD
0  // STA IP mode: DHCP/mDNS
```

PCで開くアドレスは、1行目から決まります。

```text
http://pupilcamera.local/
```

mDNSを通さないネットワークや、常に数値IPで接続したい場合は固定IPを使います。

```text
1  // STA IP mode: static IPv4
192.168.1.123  // ESP32 address
192.168.1.1  // gateway
255.255.255.0  // subnet mask
192.168.1.1  // DNS
```

この例の接続先は`http://192.168.1.123/`です。固定IPは使用中のLANと同じサブネットにし、ほかの機器やルーターのDHCP割り当てと重複させないでください。

STA接続に失敗してもAPへ自動移行しません。意図しない無線ネットワークを作らず、30秒後にSTA接続を再試行します。

接続失敗時はシリアルモニタに`reason=201 (NO_AP_FOUND)`、`reason=202 (AUTH_FAIL)`、`reason=204 (HANDSHAKE_TIMEOUT)`などの理由コードと名称を表示します。録画開始後の再試行で失敗した場合は`.999.txt`ログにも記録します。

### 2: AP（ESP32がWi-Fi親機になる）

10、11行目で指定したSSIDとパスワードのネットワークをESP32が作ります。PCをそのSSIDへ接続し、次を開きます。

```text
http://192.168.4.1/
```

APのIPはコードで`192.168.4.1`へ固定されています。

### ファイルの日時

STAモードで起動時のNTP同期に成功すると、その後に作成するAVI・ログ・CSVのFAT作成日時と更新日時へ実日時を使用できます。Wi-Fi OFFまたはAPモードでは起動時にNTP同期しないため、完全な電源断後の実日時は保証できません。`.time.csv`の`timestamp_ms`は実日時ではなく、ESP32起動後の経過時間です。

## Web画面

`ADDRESS`を上記で決まるホスト名またはIPに置き換えます。

| 機能 | URL |
|---|---|
| 操作画面 | `http://ADDRESS/` |
| 静止画 | `http://ADDRESS/capture` |
| MJPEGライブ映像 | `http://ADDRESS:81/stream` |
| SDファイル管理 | `http://ADDRESS:8080/` |

Web画面に認証はありません。信頼できるローカルネットワーク内だけで使用し、インターネットへのポート開放はしないでください。

ライブ映像はポート81の1クライアントだけを処理します。録画タスクから要求時の最新フレームだけを受け取り、遅延した中間フレームは蓄積しません。送信が5秒以上進まないクライアントは切断し、ソケットを解放します。STAモードでは、普段は省電力の`WIFI_PS_MIN_MODEM`を使用し、ライブ映像を開いている間だけモデムスリープを解除します。以前のポート82は、RAM・タスク・ソケットの消費を減らすため起動しません。

## 物理操作

- BOOTボタン：1.5秒長押しで安全停止。状態表示LEDの点滅、またはシリアルモニタの`SD card unmounted`を確認してから電源を外せます。
- GPIO5/6：外付け状態表示LED用。GPIO6から電流制限抵抗を介してLEDのアノード、GPIO5へカソードを接続します。録画中は点灯、待機中は消灯、安全停止完了後は0.5秒間隔で点滅します。XIAOの内蔵LEDや、3.3 Vから給電する撮影用照明とは別物です。
- GPIO43：未接続/HIGHで録画、GND/LOWで録画停止。
- GPIO44：Wi-FiモードがSTAまたはAPのとき、未接続/HIGHでWi-Fi起動、GND/LOWでWi-Fi停止。

GPIO44を未接続にすると内部プルアップによりWi-Fiが起動します。常にWi-Fiを使わない場合は、GPIO操作ではなく`wifi mode = 0`を設定してください。

## ブラウンアウト対策

ブラウンアウト検出器は、低電圧時の不正動作やデータ破損を防ぐため常に有効です。Wi-Fiを使用する設定では、起動時の電流ピークがカメラ初期化と重ならないよう、Wi-Fiを先に段階的に起動します。その間はCPUを一時的に80 MHzへ下げます。STA接続は送信電力13 dBmで開始し、接続できない場合だけ15 dBmで再試行します。接続後は`WIFI_PS_MIN_MODEM`を有効にし、ライブ映像の表示中だけ通信安定性を優先して解除します。APモードの送信電力は13 dBmです。

直前のリセット理由が`ESP_RST_BROWNOUT`だった場合は、再起動ループを防ぐため、その1回の起動ではWi-Fiを無効にしてSD録画を優先します。電源を完全に切って入れ直すと、次回はconfigのWi-Fi設定を再び試します。シリアルモニタと`.999.txt`には`Brownout recovery: WiFi disabled for this boot`と記録されます。

これらは電流ピークを軽減する対策であり、電源容量不足そのものは解消できません。十分に充電され、必要なピーク電流を供給できる3.7 V LiPoと、抵抗の小さい短い配線を使用してください。[Seeed Studioの仕様](https://wiki.seeedstudio.com/xiao_esp32s3_getting_started/)では、OV2640の640×480動作について最大約0.65 Aと案内されています。

## 注意事項

- 録画中の突然の電源断は、AVIやFATファイルシステムを破損させる可能性があります。通常はBOOTボタンによる安全停止を使用してください。
- ライブ映像の閲覧中はWi-Fi送信と画像コピーが増えるため、Wi-Fi OFF時より消費電力が増えます。
- `config.txt`にはWi-Fiパスワードが入るためGit管理対象外です。公開用には`config.example.txt`を使用してください。
- SD書き込みタスクのスタックは8192バイトです。起動時にはESP32 Arduinoコアのバージョンを表示し、SDタスクの最小空きスタックを初回・100回の書き込みごと・AVI終了時にシリアルモニタと`.999.txt`ログへ記録します。最小空きスタックが0に近い場合は、スタック不足の可能性があります。
